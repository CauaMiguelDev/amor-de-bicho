# Casa Focinho (demo)
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
React, TypeScript, Vite, Tailwind CSS and Lucide React as requested in the user's supplied reference.
## Users
Prospective clients of the freelancer (veterinary clinics and pet shops) who see the page as a portfolio piece, and, once adapted, the clinic's own pet guardians.
## Product Purpose
A demonstration landing page for a 24-hour veterinary clinic with pet shop, reusable as a template for real clients.
## Demo data
Brand "Casa Focinho", phone, address, rating, review counts and testimonials are fictional and live in `src/brand.ts`. The phone uses DDD 00, which does not exist in Brazil, so it can never ring a real number. The footer and the reviews section say the content is illustrative, and the page is marked `noindex`.
## Brand Commitments
The supplied CozyPaws reference pins mint and forest green, orange actions, DM Serif Display and Inter, prominent animal photography, responsive design, custom buttons, and rich smooth motion. Brand mark is an original concept.
## Constraints
Never reuse data from a real business in the demo. Pets react with motion and hearts, not speech bubbles. The map is an illustration (no real location is embedded). When adapting for a client, replace every value in `src/brand.ts` and remove the demo notices.
## Scope interpretation
A full landing page with the reference hero followed by care, manifesto, reviews, location, and contact. The reference's no-scroll constraint describes the hero; the rest of the page scrolls.
